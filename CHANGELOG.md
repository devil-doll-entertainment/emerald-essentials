## [1.1.0] — 2026-09-11

### Added

- Multi-loader architecture for Minecraft 1.21.1 supporting both Fabric and NeoForge.
- Emerald Dagger weapon with agile attack speed and stealth/backstab synergy.
- Data-driven amethyst enchantments: Amethyst Levitation, Curse of Blind Mining, Curse of the Shadows, and Thief's Stride.
- Illusional Flower with dynamic particles and sound effects.
- Full bilingual in-game localization (English `en_us` and Spanish `es_es`).
- Canonical task runner workflow via `Justfile`.
- Automated code formatting and linting via Spotless and Checkstyle.
- Automated unit test suite powered by JUnit 5.
- Continuous integration and release automation via GitHub Actions.

### Changed

- Rebalanced emerald armor to a competitive tier (19 total defense, +1.0 toughness, 25 enchantability).
- Standardized emerald tools to diamond mining tier with 550 durability.

### Removed

- Removed legacy MCreator workspace artifacts and Forge 1.19.2 dependencies.
